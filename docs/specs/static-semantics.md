# cino 静的意味論仕様（ドラフト）

## 1. 対象範囲

本書は次の静的検査を定義する。

- 型検査
- 網羅性検査
- 純粋性検査
- クロージャ制約検査

## 2. 型システム

レコードは構造的、列挙型は原則として名前的に扱う。

- リテラル: `Int`, `Decimal`, `Bool`, `String`
- ジェネリクス: `List<T>`, `Map<K, V>`, `Option<T>`, `Result<T, E>`
- ユーザー型: `record`, `enum`

型エラーはコンパイル時に報告し、位置情報を必須とする。

## 3. 関数契約

- `update`: 入力は `state` と `event` を1つずつ、戻り値は `(State, List<Action>)`
- `query`: 入力は `state` と `query` を1つずつ、戻り値はドメイン `Result`
- 暗黙変換は原則禁止。許可する場合は仕様で明示する。

## 4. パターンマッチ規則

- `enum` に対する `match` は全バリアント網羅必須
- ガード付きアームは、それ単独では網羅扱いにしない
- 到達不能アームは診断を出す

## 5. 純粋性規則

ドメインコードで禁止する操作:

- 可変グローバル束縛
- 外部関数呼び出し
- 不純プリミティブ（時刻/乱数/I/O）
- 例外機構

許可する操作:

- 純粋なローカル束縛
- 決定的式評価
- `Action` 値の構築

## 6. クロージャ規則（MVP）

クロージャは次の制約下でのみ許可する。

- 純粋であること
- 不変値のみをキャプチャすること
- 非エスケープであること（保存・返却・`State` 格納を禁止）
- 主用途は `map` / `filter` / `fold`

エスケープクロージャはコンパイルエラーとする。

## 7. 決定性規則

- `Map` 反復順が観測可能な場合は仕様で固定する
- 数値演算（特に小数）の挙動を実行系契約で固定する
- 未定義動作は認めない

## 8. 診断分類

- `E-TYPE-*`: 型不一致、未解決シンボル、ジェネリクス不正
- `E-MATCH-*`: 非網羅、到達不能
- `E-PURE-*`: 純粋性違反
- `E-CLOSURE-*`: キャプチャ/エスケープ違反
